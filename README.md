# formatted-ppt

住商・ファーマシーズのスライド作成。篠田さん作

`sumitomo-pptx` スキルで、住友商事ブランドのパワポを作る／既存スライドを住商フォーマットに変換する。

## 導入

`INSTALL.md` を Claude Code に読ませるだけ。詳しくは `はじめにお読みください.txt`。

## フォルダの使い方

```
入力/
├── テキスト/    ゼロから資料を作るとき、素材のテキストを置く
└── スライド/    既存スライド(.pptx/.pdf)を住商フォーマットに変換するとき置く
出力/            できあがったスライド一式
```

| やりたいこと | 置く場所 | 頼み方 |
|---|---|---|
| ゼロから資料を作る | `入力/テキスト/<案件名>/` | `入力/テキスト/<案件名> のテキストでスライドを作って` |
| 既存スライドを住商化する | `入力/スライド/<案件名>/` | `入力/スライド/<案件名> のスライドを住商フォーマットに変換して` |

詳しくは `入力/スライド/README.md` を参照。

## 成果物

`出力/<案件名>/` に、`.pptx` 本体と一緒に `spec.json`（設計図）が残る。
修正はテキストから作り直すのではなく、**`spec.json` を直して再ビルド**するのが速い。
変換の場合は `mapping.md`（元スライドとの対応表）も付く。
