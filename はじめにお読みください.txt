住商PPTスキル（sumitomo-pptx）導入キット
========================================

手でコマンドを打つ必要はありません。やることは2つだけです。


【1】このZIPを、どこでもよいので分かる場所に展開する
      （例：デスクトップ）


【2】展開したフォルダを Claude Code で開き、
      下の一行をそのまま貼り付けて送る

------------------------------------------------------------
このフォルダの INSTALL.md を読んで、書いてあるとおりにセットアップして。終わったら結果を報告して。
------------------------------------------------------------

      あとは Claude が、スキルの配置・必要なライブラリの導入・
      動作確認まで全部やって、結果を報告します。


【3】報告が出たら Claude Code を再起動する
      再起動しないとスキルは読み込まれません。

      再起動後の使い方は、内容を貼って一行だけ。

      ------------------------------------------------------------
      【内容】を住商パワポでつくって
      ------------------------------------------------------------

      体裁の注文（1枚1メッセージ、図をつける、文字の大きさ、
      仕上がりの目視チェックなど）は書かなくて構いません。
      スキルの中に入っていて、毎回自動で適用されます。


----------------------------------------
うまくいかないとき
----------------------------------------
・「Python 3.10 以上が必要」と言われた
    → python.org または Microsoft Store から導入してください。
      インストーラでは「Add python.exe to PATH」にチェックを入れます。
      入れ終えたら、もう一度【2】のプロンプトを送るだけでOKです。

・エラーが出た
    → エラーの文章をそのまま Claude に貼ってください。
