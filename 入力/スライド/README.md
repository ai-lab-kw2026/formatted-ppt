# 入力/スライド

**他社・他部署の既存スライドを、住商フォーマットに変換したいときに置く場所。**

（ゼロから資料を作る場合は、代わりに `入力/テキスト/` を使ってください）

## 置き方

案件ごとにサブフォルダを切ります。

```
入力/スライド/
└── 案件名/
    └── deck.pptx
```

対応形式は **`.pptx`** と **`.pdf`** です。
`.ppt`（旧形式）は PowerPoint で `.pptx` に保存し直してください。

## 頼み方

Claude Code に一行で頼みます。

```
入力/スライド/案件名 のスライドを住商フォーマットに変換して
```

## できあがるもの

`出力/案件名/` に一式が入ります。

| ファイル | 中身 |
|---|---|
| `<案件名>.pptx` | **成果物** |
| `mapping.md` | 元スライドとの対応表。どれを分割・統合・削除し、タイトルをどう書き換えたかが載る |
| `spec.json` | 設計図。修正はここを直して再ビルドすれば1分で反映できる |
| `digest.json` / `digest.md` | 元スライドから抽出した生データ |
| `media/` | 元スライドから取り出した画像 |

## 変換の方針

体裁だけ差し替えるのではなく、**住商ルールで作り直します**。

- タイトルは言い切りの文に書き換わります（「今後の課題」→「課題は納期と要員の2点に絞られる」）
- 1枚1メッセージになるよう分割・統合するため、**枚数は元と変わります**
- 図は PowerPoint のネイティブ図形で描き直すので、納品後に文言もサイズも色も直せます
- 引き継ぐ画像は写真・スクリーンショットだけです
- 元デッキの色・ロゴは持ち込みません（住商ブランドが正）

変更点は全部 `mapping.md` に残るので、そこで確認してください。
